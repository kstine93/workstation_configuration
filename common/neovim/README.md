# README.md -- Neovim

This directory contains configurations for using Neovim.
These configurations have been tested on a MacOS setup, bute should work roughly the same in most systems.


## Configuration
The init.lua and keymap.lua files should be hosted at this path: `~/.config/nvim/`

## Plugins
Plugins should be hosted at this path: `~/.local/share/nvim/site/pack/<PLUGIN-NAME>/`
